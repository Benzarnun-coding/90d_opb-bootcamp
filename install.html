คู่มือติดตั้งแอปบนมือถือ

90 DAY ONE PERSON BUSINESS BOOTCAMP · ติดตั้งแล้วเปิดจากไอคอนได้เหมือนแอป ไม่ต้องพิมพ์ลิงก์ทุกวัน และรับแจ้งเตือนก่อนปิดรอบได้

opb-bootcamp.netlify.app
⚠️ ก่อนเริ่ม: ต้องเปิดลิงก์ใน "เบราว์เซอร์จริง" เท่านั้น
ถ้ากดลิงก์จาก LINE / Facebook / Instagram / Discord มันจะเปิดในหน้าต่างเล็ก ๆ ของแอปนั้น ซึ่งติดตั้งไม่ได้ ให้กดออกมาเปิดในเบราว์เซอร์ก่อน:
LINEกด ⋯ หรือ ⋮ มุมขวาบน → เปิดด้วยเบราว์เซอร์
Facebook / Messengerกด ⋯ มุมขวาบน → เปิดในเบราว์เซอร์
Instagramกด ⋯ มุมขวาบน → Open in browser
Discordกดลิงก์ค้าง → คัดลอกลิงก์ → ไปวางใน Safari หรือ Chrome

🍎 iPhone / iPadใช้ Safari หรือ Chrome ก็ได้ (iOS 16.4 ขึ้นไป) ทำตามรูปด้านล่าง

  1. เปิดเบราว์เซอร์แล้วพิมพ์ opb-bootcamp.netlify.app
  2. Safari: กดปุ่ม แชร์ ⬆ แถบล่างตรงกลาง
    Chrome / อื่น ๆ: กด ⋯ มุมขวาล่าง → Share (รูปที่ 1)
  3. ในหน้าแชร์ เลื่อนรายการลงมา กด "Add to Home Screen" / "เพิ่มไปยังหน้าจอโฮม" ➕ (รูปที่ 2 · ถ้าไม่เห็น กด "Options" หรือเลื่อนลงอีก)
  4. กด "เพิ่ม / Add" มุมขวาบน → ไอคอน 🐉 จะไปอยู่บนหน้าจอโฮม
  5. เปิดจากไอคอน → ใส่อีเมล + รหัสที่ทีมงานแจก → เข้าได้เลย
🔔 อยากได้แจ้งเตือนก่อนปิดรอบ: ต้องเปิดแอปจากไอคอนบนหน้าจอโฮม (ไม่ใช่จาก Safari) แล้วไปที่ MY STATUS → เปิดเตือนก่อนปิดรอบ กด "อนุญาต" · ใช้ได้กับ iOS 16.4 ขึ้นไป

🤖 Android · ChromeSamsung, Xiaomi, OPPO, vivo, realme, Pixel ที่มี Chrome

  1. เปิด Chrome แล้วพิมพ์ opb-bootcamp.netlify.app
  2. กดปุ่ม "📲 ติดตั้งแอป" ที่มุมบนของเว็บ (ถ้าเห็น) → กด ติดตั้ง จบเลย
  3. ถ้าไม่เห็นปุ่ม: กด ⋮ มุมขวาบนของ Chrome → "ติดตั้งแอป" หรือ "เพิ่มไปยังหน้าจอหลัก" → ติดตั้ง
  4. ไอคอน 🐉 จะอยู่ในหน้าจอหลัก / ลิ้นชักแอป เปิดแล้วล็อกอินได้เลย
🔔 เปิดแจ้งเตือนได้ที่ MY STATUS → เปิดเตือนก่อนปิดรอบ แล้วกด "อนุญาต"

📱 Samsung Internetเบราว์เซอร์ที่ติดมากับมือถือ Samsung

  1. เปิด Samsung Internet แล้วพิมพ์ opb-bootcamp.netlify.app
  2. กดไอคอน ⬇ ที่แถบที่อยู่ (ถ้ามี) → ติดตั้ง
  3. หรือกด ≡ เมนูมุมขวาล่าง → "เพิ่มหน้าไปยัง" → "หน้าจอหลัก" → เพิ่ม
ถ้าติดตั้งไม่ได้ ใช้ Chrome แทนตามวิธีด้านบน ทุกเครื่อง Samsung มี Chrome อยู่แล้ว

📱 Huawei / Honor (ไม่มี Google)ใช้ Huawei Browser หรือ Petal

  1. เปิด Huawei Browser แล้วพิมพ์ opb-bootcamp.netlify.app
  2. กด ⋮ หรือ ≡ ด้านล่าง → "เพิ่มไปยังหน้าจอหลัก" (Add to home screen) → เพิ่ม
ถ้ามี Edge หรือ Chrome ติดตั้งอยู่ ใช้ตัวนั้นจะได้ปุ่ม "ติดตั้งแอป" และแจ้งเตือนครบกว่า

📱 Xiaomi (Mi Browser) · OPPO · vivoถ้าไม่อยากใช้ Chrome

  1. เปิดเบราว์เซอร์ของเครื่อง แล้วพิมพ์ opb-bootcamp.netlify.app
  2. กด ⋮ หรือ ≡ → หาเมนู "เพิ่มไปยังหน้าจอหลัก" / "Add to Home screen" / "ทางลัด" → เพิ่ม
แนะนำให้ใช้ Chrome มากกว่า เพราะรองรับแจ้งเตือนและอัปเดตอัตโนมัติ

💻 คอมพิวเตอร์Chrome / Edge / Brave บน Windows และ Mac

  1. เปิดเว็บ opb-bootcamp.netlify.app
  2. กดปุ่ม "📲 ติดตั้งแอป" บนเว็บ หรือไอคอน ⊕ ทางขวาของแถบที่อยู่ → ติดตั้ง
  3. แอปจะเปิดเป็นหน้าต่างของตัวเอง และมีไอคอนใน Start / Dock
Safari บน Mac: เมนู ไฟล์ → เพิ่มไปยัง Dock (macOS Sonoma ขึ้นไป) · Firefox ยังติดตั้งเป็นแอปไม่ได้ ใช้เว็บปกติ

✅ หลังติดตั้งทำครั้งเดียว

  1. เปิดจากไอคอน 🐉 → ใส่ อีเมลที่ลงทะเบียน + รหัสที่ทีมงานแจก (กด 👁 เช็คตัวพิมพ์ใหญ่-เล็กก่อนกดเข้า)
  2. เข้าครั้งแรกตั้งชื่อตัวละคร แต่งตัว แล้วเลือกเป้าสัปดาห์
  3. ไปที่ MY STATUS → กด 🔔 เปิดเตือนก่อนปิดรอบ → อนุญาต · ระบบจะเตือนตอน 2 ทุ่มถ้าวันนั้นยังไม่ส่งงาน
  4. ส่งงานทุกวันด้วยปุ่ม ＋ ส่งงาน ตรงกลางแถบล่าง วางลิงก์แล้วกด SUBMIT

❓ ติดปัญหาเช็คตามนี้ก่อนแจ้งทีมงาน

ไม่มีปุ่ม "ติดตั้งแอป" / ไม่มีเมนู "เพิ่มไปยังหน้าจอหลัก"
คุณกำลังเปิดอยู่ในหน้าต่างของ LINE/Facebook — ออกมาเปิดใน Safari (iPhone) หรือ Chrome (Android) ก่อน · ถ้าเป็น Chrome ให้อัปเดต Chrome เป็นเวอร์ชันล่าสุด
iPhone หาเมนู "Add to Home Screen" ไม่เจอ
ในหน้าแชร์ให้เลื่อนรายการลงอีกนิด เมนูอยู่ค่อนข้างล่าง (ดูรูปที่ 2) · ถ้า iOS ต่ำกว่า 16.4 ต้องใช้ Safari เท่านั้น · ถ้าเปิดจากในแอป LINE/Facebook จะไม่มีเมนูนี้ ให้ออกมาเปิดในเบราว์เซอร์ก่อน
ขึ้นว่า "รหัสไม่ถูกต้อง"
กด 👁 ดูว่าพิมพ์ตรงกับรหัสที่แจกไหม (ตัวพิมพ์ใหญ่-เล็กมีผล) · ถ้าเคยเข้าได้แล้วแต่เข้าเครื่องใหม่ไม่ได้ แจ้งทีมงานให้กด "รีเซ็ตรหัส" ให้
ไม่ได้รับแจ้งเตือน
iPhone ต้องเปิดจากไอคอนบนหน้าจอโฮม ไม่ใช่จาก Safari · เช็คว่าตั้งค่า → การแจ้งเตือน ของแอปนี้เปิดอยู่ · แจ้งเตือนส่งเฉพาะวันที่ยังไม่ส่งงาน ตอน 20:00
เปิดแอปแล้วเป็นหน้าเก่า ไม่อัปเดต
ปิดแอปให้สนิท (ปัดออกจากรายการแอปล่าสุด) แล้วเปิดใหม่ 1 ครั้ง
